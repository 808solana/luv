## Home page
- Page base is white. Hero is **ungated**: visitors land already in and can scroll immediately.
- Hero: compact `luv13` mark (Bold, `--paper` on `#fe0000`) that **pops in once on load** via `VerticalCutReveal` and **then flips away** — each glyph rises through an `overflow-hidden` word clip with a character-level stagger from the center and a spring overshoot; no scramble, no slide-out. The pop is **act 1 only** (2026-09-15): on its `onComplete` the whole slot is handed to `DepthFlipText`, which hinges the wordmark away character-by-character to *“Anyone who has a will to create is an artist” — Virgil Abloh* and then keeps trading the two lines back and forth (`loop`, 2026-09-15: the user asked for it to repeat for as long as they are on the hero — *"It just plays once, and then it just stops, but I want it to loop"*). One cycle is ~9.7s (mark holds 1.8s → flip 1.7s → quote holds 4.4s → flip 1.7s), and the cycle **pauses itself the moment the hero leaves the viewport** (an `IntersectionObserver` on the slot pauses the per-cycle GSAP timeline; the resume is guarded by `progress() < 1` so a finished timeline can never be replayed on top of the next one), so a looping hero is never animating to an empty room. The two acts are mounted **sequentially, never together** — Motion writes `transform` on the glyphs in act 1 and GSAP writes it on the same glyphs in act 2, so two systems on one element would fight over the inline style. The slot is a fixed `h-[0.9em]` line box with both faces `absolute inset-0` centred in it, which is why the hand-off moves nothing: the pop's `1.2em` clip window is itself centred on a `0.9em` flow line (the `-my-[0.15em]` trick), so the ink box and the flow height are identical on both sides (probed frame-by-frame — the last pop frame and the first flip frame report identical `glyphTop` / `glyphH` / `h1Top` / `rowTop` / `heroH` / `docH` at both 375 and 1920, and the control row's `rowTop` never varies while the title cycles). The title is therefore **`<HeroTitle />`** (`web/components/marketing/hero-title.tsx`, client) in `web/app/page.tsx`, **not a raw `<h1>`** — that wrapper owns the sequence and the size ladder (`HERO_MARK_SIZE`). The quote is a `p` at `text-base sm:text-2xl md:text-[1.75rem] lg:text-[2rem]` in curly quotes, closing with a **no-break space** before the `”` (2026-09-15 (3): the user wanted the space-bar gap the type was missing — `\u00A0` gives exactly one space, `6.71px` at the `lg` 32px quote, while refusing to become a line-break point that would strand the quote mark alone). The attribution is an **`aside` inline to the right on the same baseline** — a real space, then `inline-block whitespace-nowrap text-[0.55em] tracking-widest opacity-80` carrying `— Virgil Abloh` (2026-09-15: it used to be a `sub` block line *under* the text; the user moved it right, then asked for the letters to be opened up). The real space is what keeps `innerText` / copy identical to the `sr-only` string, `nowrap` is what keeps the name whole, and **`tracking-widest` is a correction rather than a flourish**: the wrapper's `tracking-tight` computes on the *88px* mark and inherits as a **length** (`-2.2px`), which was `-0.125em` on the 17.6px attribution — the reason the name looked jammed. That width also sets the wrap points: **one line at 414 / 640 / 768 / 1024 / 1440 / 1920** with the line centred exactly on the viewport, **two centred lines at 375 / 390** (sentence whole, the name beneath), and below ≈338px the sentence wraps with the name trailing its last line — every form 39.7–41.6px inside the 50.4px base slot. The phrase deliberately carries **no `text-balance` / `text-pretty`**: with an inline-block aside those algorithms pull a word down instead of letting the atom finish the line, splitting a sentence that fits. Under `prefers-reduced-motion` both acts degrade to a plain opacity crossfade with the same holds, and the cycle still loops. A11y is per layer: each phrase renders an `sr-only` plain-text line plus an `aria-hidden` glyph container, so the `h1`'s accessible name stays `luv13` even while the quote is the visible face.
